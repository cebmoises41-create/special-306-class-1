📘 SESIÓN 1 — USO DE "WOULD"

Invitaciones · Peticiones de instrucciones y direcciones

📖 EXPLICACIÓN: USE OF "WOULD"

Would es un verbo modal que se usa para hacer invitaciones y pedir instrucciones o direcciones de forma cortés.

1️⃣ Invitaciones — Would you like to...?

Se usa para invitar a alguien a hacer algo.

Would you like to + verbo en infinitivo + complemento?
✅ Would you like to watch a movie? → ¿Te gustaría ver una película?
✅ Would you like to have dinner with us? → ¿Te gustaría cenar con nosotros?
✅ Would you like to go to the park? → ¿Te gustaría ir al parque?

Respuestas:

✔️ Yes, I'd love to.
❌ No, thanks. Maybe another time.

2️⃣ Pedir instrucciones o direcciones — Would you tell me...?

Se usa para pedir información de forma educada: cómo llegar a un lugar o cómo hacer algo.

Would you tell me + how to / where / how I can + verbo?
✅ Would you tell me how to get to the station? → ¿Me dirías cómo llegar a la estación?
✅ Would you tell me where the bathroom is? → ¿Me dirías dónde está el baño?
✅ Would you tell me how to open this box? → ¿Me dirías cómo abrir esta caja?

Respuestas:

✔️ Of course. Go straight and turn left.
✔️ Sure. It's on the second floor.

⚠️ Diferencia clave

Estructura Uso Ejemplo
Would you like to... Invitar Would you like to dance?
Would you tell me... Pedir info/instrucciones Would you tell me how to dance?
